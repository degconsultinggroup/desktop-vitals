# Desktop Vitals settings. Copy this file to %APPDATA%\DesktopVitals\watch.txt and edit it there,
# then close and reopen the app. Everything here is optional: scripts, scheduled tasks and system
# stats show up on their own.

# ---- Pinned: keep an eye on an app or a command ----
# Label = match
# A match ending in .exe is a process name. Anything else is text found in the command line.
#
# Chrome = chrome.exe
# My server = my-project\server.js

# ---- Bots: things that should keep working, not just keep running ----
# Add "| check:" to put a line in the Bots card. The check is the bot's last sign of work:
#   a file it rewrites, a folder it writes into, or a local http health address
#   (127.0.0.1, ::1, or localhost only). Amber after 5 quiet minutes.
# "| code:"  the bot's folder. Click opens it in Cursor or VS Code.
#
# Price bot = price_bot.py | check: C:\bots\price\heartbeat.json | code: C:\bots\price
# Local API = uvicorn | check: http://127.0.0.1:8000/health

# ---- AI ----
# Known AI names (Claude, Cursor, Ollama, OpenClaw ...) go in the AI card, not Bots or Pinned.
# "| ai" puts any other line there. "| kind:" sets its tag: Agent, App, Model, Bot or Watching
# (Watching shows as Pinned).
#
# Research agent = agent_loop.py | ai | kind: Agent
#
# Models are found in "models" folders (C:\models, %USERPROFILE%\models) and the Hugging Face,
# Ollama and LM Studio stores. Add other folders, one line each:
# @models = D:\my-models
#
# The review screen writes these into %APPDATA%\DesktopVitals\review.txt (never into this file):
# @hide = <name>             don't show something Desktop Vitals found on its own
# @kind = <name> | Agent     change the tag of something it found
# @reviewed = <date>         the first-run review is done
# The same @ lines still work here if you prefer to keep everything in one file.

# ---- Processor temperature (read only) ----
# Windows doesn't hand CPU temperature to normal apps. If a sensor tool already keeps writing a
# JSON file like
#   {"ts": "2026-10-10T14:03:22Z", "cpu_temp_c": 48.5, "cpu_pkg_power_w": 21.0}
# point Desktop Vitals at it. When the file is missing or stale, the UI says so. Nothing is started.
#
# @temperature-file = C:\ProgramData\MySensor\last.json
